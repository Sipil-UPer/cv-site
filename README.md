# cv-site

Published site of the prodi sipil lecturer dashboard
(https://sipil-uper.github.io/cv-site/).

Do not edit files here by hand. Since 2026-10-09:

- pages (HTML/JS, `config.js`, this README) are edited in `cv-data/site/`;
- `data.json` is written by `cv-data/bangun.py`;
- `cv-data/bangun-dan-push.bat` copies `site/` here and pushes both repos.

Edits made directly in this repo are overwritten on the next build.
